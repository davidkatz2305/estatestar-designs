# EstateStar – Designentwürfe

Zwei statische Website-Entwürfe mit gemeinsamer Auswahlseite. Entwurf 1: Cinematic. Entwurf 2: Beyond Space mit Three.js.

## GitHub Pages

Die Website liegt vollständig im Repository-Root. Pages-Quelle: Branch `main`, Verzeichnis `/`. `.nojekyll` ist vorhanden. Keine Installation, kein Build auf GitHub erforderlich.

- `/`: Auswahlseite
- `/entwurf-1/`: Entwurf 1
- `/entwurf-2/`: Entwurf 2

Nach Veröffentlichung kann die Adresse in WhatsApp geteilt werden; die Auswahlseite enthält zusätzlich eine WhatsApp-Schaltfläche. Eine Anmeldung zum Betrachten der öffentlichen GitHub-Pages-Seite ist nicht erforderlich.

Fotos, Filme und Marken stammen von EstateStar. Das 3D-Modell ist eine abstrakte Architekturvisualisierung. Three.js ist unter MIT lizenziert, siehe `entwurf-2/vendor/THREE-LICENSE.txt`.

Kontaktformulare öffnen einen E-Mail-Entwurf. Externe Filme und der aktiv geladene Rundgang werden vom bisherigen Anbieter bereitgestellt. Die produktive Domain wird durch dieses Projekt nicht umgestellt.
